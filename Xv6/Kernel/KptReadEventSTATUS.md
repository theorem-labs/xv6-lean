# Shared kernel page-table ordinary read event

The seven modules Defs, Spec, Pure, Access, Power, Proofs and Link compile
against the actual native ordinary eight-byte RAM read event. The final Link
discharges all slot access, ownership and native memory-rule dependencies.
No caller supplies a physical slot, memory-read result, invariant-restoration
callback or successful subprogram theorem.

The public precondition supplies the shared invariant, a canonical tree
snapshot, the shared bound and its actual boot/view credential, a pure Maps
path in that snapshot, and the original reservation. The complete read request
is retained with exact selected-path address, nondevice and nonexclusive
guards. The selected level ranges over the three actual Sv39 levels.

At the actual pre-read state, the proof opens the shared invariant at top.
Snapshot agreement supplies the current mapped path; bound agreement equates
the current pinned tree's bound with the client's credential. A selected-slot
accessor retains a wand for the entire current tree. The physical word is
existential, with canonical equality to the reference and exact equality
when the reference is a nonleaf. No leaf physical value is fixed in advance.

The existing actual TSO rule derives allowed bytes at every permitted view
from those pins and the real publication credential. The proof restores the
same power interpretation, slot and complete tree, then closes the invariant.
Only afterwards does the native read premise drop from top to the empty mask.
The word remains existential inside each quantified chosen view. The actual
memory event supplies the view receipt and its single guard; the callback
gets the canonical/exact-nonleaf fact, unchanged reservation, all persistent
clients and the genuine residual-program WP. No invariant remains open across
the event or continuation.

This is one ordinary read event. Exclusive rereads, conditional writes,
complete shared walks, TLB coherence, translated instructions and boot pinning
remain separate layers. The native dead-generation and actual request-error
machinery remain in the underlying rule; the supplied RAM/plain guards select
this event branch without changing the generated semantics.
