Original-tier KPT source branch

SieOffPacket's identity tier permits either Bare or KPT translation. A
complete source dispatcher must therefore preserve identity-tier KPT inputs,
in addition to the already proved full-tier function and Bare branch.
This adapter consumes the actual opened KPT arm at either tier. It extracts
its arbitrary two-word save area in that same tier, retaining the literal
stack tail and all original source resources.

Identity kernel text monotonically supplies the requested tier's native
fetch windows. Actual source hardware plus the explicit same-hart boot-PMA
cell derive configuration, and hardware ownership supplies the generation
certificate. No root, initial phase, known save word, Config or execution
rule is an extra function premise. The final Link invokes the actual native
fourteen-cycle shared-Sv39 function and its phase/result proofs.

The full source capability is restored in the original tier after actual
SP/callee-saved restoration; the source CPU-address result is computed from
the entry hart's pinned TP. All source stack, timer, translation shot,
hardware, text, PMA and caller-frame ownership remains accounted for. The
branch predicate itself is produced by the subsequent source dispatcher,
which will open the original capability and select its actual slot.
No boot reachability or full native source-input inhabitation is inferred.
