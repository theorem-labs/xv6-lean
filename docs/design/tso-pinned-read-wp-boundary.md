# Native pinned-read event boundary

This boundary connects the actual ordinary and exclusive RAM read event
rules to the source context-free publication and pin resources. Owned files
are TsoPinnedReadWP Defs/Spec/Pure/Proofs/Link, with proof helpers if needed.
The three public contracts use existing machine capacity, era names and
full dependent requests. No camera, new interpreter or KPT invariant is added.

The ordinary rule supports arbitrary byte counts, fractions and physical
byte values. It derives all-view byte membership from the actual native
TsoPinnedRead slotRead theorem, then assembles a word for each common view.
The continuation receives that word and membership of every byte in its
existing allowed set, while the entire original slot, publication
credential and reservation remain owned. It does not equate the observed
word with the currently owned physical word. The actual MemoryReadWP rule
pays the view-authority update; the resource proof restores the original
complete power interpretation.

The PTE specialization uses eight bytes and the exact leaf-conditioned
PteCanonical.slotSet. All ordinary reads return canonical equality;
interior reads return exact equality. The physical slot's value function
is deliberately independent of the canonical reference. The actual pin
and publication constraints, rather than an unchecked equality premise,
justify the observed mapping.

The exclusive rule reads eight bytes at the log top and returns the actual
owned physical word plus its real snapshot reservation. Its full physical
readback follows from the native heap authority and pinned byte fragments;
it requires no publication credential. It retains every timestamp, floor,
allowed set and publication anchor. Native blocked rereads clear the local
reservation and retry as in the existing rule; successful rereads install
the exact snapshot. The direct rule does not claim the slot can be kept
open across a shared KPT invariant: a later resource accessor must open and
close that invariant at each event.

All rules retain arbitrary request metadata and actual tag/error residuals.
The RAM and plain/exclusive classifications are explicit pure premises;
checked supervisor wrappers must establish them separately. One real read
step pays the advertised later. The next operational layer will use these
rules in the actual checked PTE read wrappers and hardware walk, including
the separate exclusive reread/update branches.
